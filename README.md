# 云岫灵田 · 宗门岗位篇

在线游玩：https://aibelieve27.github.io/yunxiu-lingtian/
源码仓库：https://github.com/AIbelieve27/yunxiu-lingtian

这是修仙宗门的单人放置经营游戏。玩家选择岗位，弟子轮值生产；通过粮食盈余、仓储、招募和关键设施逐步建立能够持续运转的宗门。资源积累与节奏参考 Kittens Game，代码与画面独立实现。

## 开始经营

开局已有灵田和四名弟子。先查看灵植岗位的收成与冬季预估，再安排轮值、留存口粮，通过库务出售盈余支付俸禄。宗门可以切换玩家岗位与弟子岗位；进入任职页面处理招聘、营造、研究、财务或调查。

- 灵植队长看实际产量；副宗主依赖部门报告。其他岗位的账报可能过时或失实。
- 人事通过接触积累判断，从外貌逐步辨识能力、性格与为人。公开评议和核实事实可交接，NPC 的私人了解不会随玩家换岗自动获得。
- 可安排 8、12、16 小时工作和上班时间，并选择俸禄、加班费与济困福利。连续生产需要错开班次；长班影响疲劳、心情与个人收入。
- 招聘遇住房不足会提出需求，副宗主协调、营造岗执行。营造和研究仍需真实材料、仓储和工时。
- 经济压力、胆量、性格和监管共同影响违规机会。核对收成、盘点、钱款与物流提供不同证据；关联调查能继续寻找相关人，两类独立证据才能结案。

## 本地运行

需要 Node.js 22，无需安装依赖。

```powershell
npm start
npm test
npm run build
```

本地地址为 http://127.0.0.1:4173/ 。构建后可双击 dist/index.html 离线游玩。手机可直接使用上述在线地址，当前版本是响应式网页游戏，尚未打包为 Android/iOS 安装包。

## 存档

自动保存到当前浏览器，离线最多结算八小时。暂停会保存且阻止离线推进。新篇使用独立存档键，不覆盖旧版存档；设置页提供导入、导出与旧篇备份。没有账号云存档，换设备前请导出。

## 更新网页

main 分支推送后，GitHub Actions 会自动测试、构建并部署 GitHub Pages。当前发布仓库属于 AIbelieve27；本机其他旧目录可能仍关联旧账号，请先检查 git remote -v，避免推错仓库。
