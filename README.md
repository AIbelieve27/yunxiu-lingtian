# 云岫灵田 · 职司渐开（2.1）

[在线游玩](https://aibelieve27.github.io/yunxiu-lingtian/) · [GitHub 源码](https://github.com/AIbelieve27/yunxiu-lingtian)

修仙宗门的网页放置经营游戏。资源循环与渐进节奏参考 Kittens Game，程序与画面独立实现。

## 这次的核心原则

页面取决于当前任职与职责：生产者看自己负责的实际工作，管理者看直接下属已提交的汇报。没有汇报就显示未汇报，切换管理岗位不会获得下属的私人认识和实时真值。

新开局只开放灵植弟子；收获、采材与建筑逐步开放更多职司。角色和 NPC 都只能切到已经开放的岗位。每个岗位首次任职都有教程，顶部“本岗教程”可以重看。

| 岗位 | 开放条件 | 职责 |
| --- | --- | --- |
| 灵植弟子 | 开局 | 自己的责任田、真实收成、提交工作记录 |
| 樵采弟子 | 累计收获 40 灵米 | 亲自采集灵木 |
| 采石弟子 | 累计采得 8 灵木 | 亲自采集青石 |
| 营造执事 | 已采得 8 木、6 石 | 经办材料与营造项目 |
| 人事弟子 | 建成弟子居 | 面谈、考察和招聘执行 |
| 库务弟子 | 建成纳物仓 | 经办库存、贸易和发俸 |
| 灵植队长 | 6 位弟子且增开过灵田 | 安排责任田、汇总灵植弟子报告 |
| 研习执事 | 建成书斋 | 学识与技艺研究 |
| 人事主管 | 建成人事堂 | 目标与下属具名考察汇总 |
| 财务主管 | 建成财务堂 | 库务报告与贸易目标 |
| 副宗主 | 议事堂、人事堂、财务堂 | 分管主管与其他直属部门，制度、预算与协调 |
| 监察执事 | 监察院及交接与复核技艺 | 收成入库核对、实物盘点、利益往来复核 |
| 巡察执事 | 建成巡察司 | 物流、关联人员及案件调查 |
| 丹房执事 | 丹房及草木丹诀 | 灵丹加工 |

## 汇报链

灵植弟子 → 灵植队长 → 副宗主。
人事弟子 → 人事主管 → 副宗主。
库务弟子 → 财务主管 → 副宗主。

NPC 轮值会提交报告；玩家需要点击“提交”完成交接。主管提交汇总后，副宗主才得到该汇总；随后基层的新数据不会自动改写旧汇总。报告保留来源、时间和引用的下属报告，可以逐层展开查看。亲自面谈需要切换人事弟子，账实核查需要切换监察，主管页面不混入执行按钮。

## 运行和验证

需要 Node.js 22，无第三方运行依赖。

```powershell
npm start
npm test
npm run build
```

本地打开 http://127.0.0.1:4173/ 。构建产物 dist/index.html 是单文件，可双击离线游玩；手机直接打开在线地址即可。当前尚未打包应用商店安装包。

main 推送后，GitHub Actions 自动测试、构建并部署。请确认 Git 远端属于 AIbelieve27，避免旧目录关联其他账号。

## 存档和时间

自动保存在本浏览器，离线最多结算八小时。暂停会保存；教程阅读期间暂缓模拟。换设备前请导出存档，没有云端账号同步。

旧岗位篇存档自动迁移，保留资源、建筑、人物与事件，按发展条件重新检查岗位。暂未开放的当前岗位切回灵植弟子，相应 NPC 转为待命。责任田和新汇报从迁移后开始记录，不伪造过去的个人收成；老版本存档仍可备份。

2 秒为游戏一小时，48 秒为一天，15 天为一季。季节、俸禄、疲劳、个人处境、监管与证据机制继续保留。

测试包含从初始唯一岗位到主管机构的无资源注入经营模拟，以及职责权限、分层报告快照、岗位教程记录、存档迁移、排班和调查规则。当前数值仍需依据试玩迭代。
